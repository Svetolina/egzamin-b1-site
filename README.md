# Egzamin B1: тренажёр (версия 2)

Статический сайт без сборки: HTML, CSS и JavaScript. Результаты хранятся в браузере (localStorage).

## Запуск
- Локально: откройте `index.html` двойным щелчком или запустите `python -m http.server` в этой папке.
- GitHub Pages: создайте репозиторий, загрузите содержимое папки, в Settings → Pages выберите ветку `main`, папку `/ (root)`.
- Любой другой статический хостинг (Netlify, Cloudflare Pages) подойдёт так же: просто отдайте папку.

## Разделы сайта
- «Тесты целиком»: все 18 тестов на одной странице (`#/tests`), отдельно образцы (`#/samples`) и прошлые экзамены по годам (`#/exams`), страница теста (`#/test/<id>`), раздел теста с таймером (`#/test/<id>/<раздел>`).
- Сейчас в тренажёре все 18 тестов: образцы 2017, 2019, 2020 и 15 прошлых экзаменов 2021–2024 годов. Кроме них есть сборник заданий 2017 года: 83 упражнения по грамматике (все) и 6 упражнений по чтению (`tests/b1-sbornik.js`), они видны только на странице «Грамматика» с меткой «Сборник».
- «Задания по типам»: аудирование, чтение, грамматика, письмо, говорение (`#/type/<раздел>`). Список собирается из всех тестов, что есть в тренажёре, с фильтрами.
- Отдельное задание: `#/task/<id>/<раздел>/<задание>`. Наверху источник и ссылка на страницу листа комиссии.

## Структура
- `assets/js/engine.js` типы заданий, проверка (в том числе частичные баллы), аудио к заданию, таймер, письмо.
- `assets/js/app.js` страницы и маршруты.
- `tests/catalog.js` каталог всех 18 тестов с официальными ссылками (лист, запись, ключ, страница комиссии).
- `tests/manifest.js` список тестов, у которых уже есть данные.
- `tests/<id>.js` данные теста: задания, ключ, транскрипции, ссылки на аудио, номера страниц листа комиссии (`page`).
- `audio/<id>/s1.m4a ...` записи, по одной на задание.
- `tools/split_audio.py` резка записи по заданиям.

## Как добавить тест
1. Создайте `tests/<id>.js` по образцу `tests/b1-2024-06.js` (вызов `B1.register({...})`). У задания: `name` (название для списков) и `page` (страница листа в PDF). Номера страниц ищутся по тексту листа.
2. Добавьте `<id>` в `tests/manifest.js`. Строка с тем же `id` уже есть в `tests/catalog.js`.
3. Разрежьте запись: `python tools/split_audio.py silences запись.mp3` покажет паузы, по ним определите границы заданий и запишите их в `cuts.json`, затем `python tools/split_audio.py cut запись.mp3 audio/<id> cuts.json`.
4. В данных аудиозадания укажите `audio:{src, plays, skip, pass2}`: `skip` это секунда, с которой начинается первое прослушивание (после паузы на чтение), `pass2` это секунда второго прослушивания.

## Ссылки на официальные файлы
- В `tests/catalog.js` прямая ссылка на файл стоит только там, где она подтверждена. Где её нет (`null`), сайт даёт ссылку на страницу комиссии и пишет об этом.
- Если комиссия переложит файл, правится одна строка в каталоге.

## Частичные баллы
- Перефразирование (грамматика VI): у пункта `parts:[{re, pts}]` и `req`, как в схеме официального ключа (например, 0,5 за предлог + 2 × 0,25 за преобразования). Проверка приблизительная, кнопка «засчитать» остаётся.
- Вопросы к части предложения: `p:{'w jakim':0.25}` для ответов, которые ключ засчитывает частично.

## Письмо
- В аудировании 2021 года есть задание с иллюстрациями (`pictures:true`: строки с `img`, ответ это номер текста). К письму может прилагаться фотография (поле `img` в данных задания, файл в `assets/img/`), как в апреле 2023.
- Кнопка «Копировать для проверки» собирает задание, требования жанра, критерии оценки и ваш текст в один запрос. Вставьте его в чат с Claude.
- `assets/js/genres.js` содержит требования к жанрам (по методичке комиссии) и шкалы оценки. Для экзаменов используется шкала `A`: 3 критерия по 10 баллов, итог из 30, как в карте оценки 2024 года.

## Говорение
Раздел пока заглушка. Будет: карточки заданий, таймер, запись голоса, самооценка по критериям (шкала приблизительная, официальные критерии не публикуются).

## Сборник заданий
- В `tests/catalog.js` у сборника `kind:'book'`, в списки тестов он не попадает. Упражнения лежат в `tests/b1-sbornik.js` как задания раздела `gram`.
- Разобраны упражнения на выбор формы, на подстановку формы по подсказке или без неё (предлоги, местоимения) и на преобразование предложений. Из чтения добавлены упражнения с выбором ответа a, b, c (надписи, короткие тексты). Не добавлены: упражнения с таблицами, с неполным ключом, несколько нестандартных по грамматике, а из чтения задания P/F/BI, сопоставления, расстановка фрагментов и слова из рамки.

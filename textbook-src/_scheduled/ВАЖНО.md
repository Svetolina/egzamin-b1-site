# Черновики из запланированной задачи (24.10.2026)

Эти темы сделаны в отдельной сессии без доступа к папке сайта, поэтому:

- **формат другой**, чем у тем в `textbook-src/` (нет `passport`, `stage`, `markup`, блоков теории `blocks`; факты R1… вместо своих префиксов; виды упражнений `typed` / `gaps` / `text-gaps` вместо `choice` / `type` / `text` / `write`);
- **источники — сайты** (elon.io, polski.info, UAM, Dziwirek, ZPE и др.), а не учебники проекта со страницами;
- не прогонялись через `tools/morfeusz_check.py` и `tools/build_preview.py`;
- `aspekt` здесь — **другая версия** уже готовой темы `textbook-src/aspekt/`. Основной остаётся та.

Использовать как сырьё: при переводе темы в основной формат брать отсюда идеи, примеры и упражнения, перепроверяя факты по правилам из `claude/textbook-howto.md`.

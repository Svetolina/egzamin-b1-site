# textbook-src — темы учебника-тренажёра

Каждая тема: `textbook-src/<тема>/extract.json` (пронумерованные факты R1… с источниками: название, точная ссылка, раздел) и `topic.json` (разделы теории со ссылками на факты + упражнения + письменные задания). Источники на странице показываются свёрнутыми у каждого раздела (через поле `facts`).

Форматы упражнений в topic.json:
- `typed` — одно поле ввода на пункт, `a` — список допустимых ответов;
- `gaps` — пропуски `{1}`, `{2}` в предложении; `a` — список (один пропуск) или словарь номер → список ответов;
- `text-gaps` — связный текст в экзаменационном формате, `text` с `{n}`, `a` — словарь;
- `writing` — задание, чек-лист и образец (не автопроверяется).

## Решения, которые можно поправить

- **Формат файлов.** Файлы предыдущих тем (czas teraźniejszy / przyszły / przeszły) в этом запуске были недоступны, поэтому формат `topic.json` воссоздан по описанию (теория + упражнения + письмо). Если поля в старых темах называются иначе — переименовать при подключении к сайту.
- **aspekt, R18 (zacząć/przestać + ndk):** найдено подтверждение только на одном сайте (elon.io, две страницы). Опубликовано одной строкой с пометкой, как решено для czasu przyszłego.
- **aspekt, R9 (двувидовые глаголы, aresztować):** только один источник (пакет UAM) — дано одной строкой.
- **aspekt, лексика упражнений:** почти все пары взяты из списков источников; несколько очень частых пар вне списков (kończyć – skończyć, dzwonić – zadzwonić, siadać – usiąść, pukać – zapukać) взяты как стандартные словарные; онлайн-проверить по sjp.pwn.pl не удалось (сайт закрыт для автоматического чтения).
- **aspekt, будущее ndk:** принимаются оба ответа — `będę pisać` и `będę pisał(a)`.
- **aspekt, глаголы движения:** даны только кратко (R20); для них планируется отдельная тема.
- **tryb rozkazujący, способ образования:** взят «школьный» двухшаговый способ из polski.info (глаголы на -m: oni − ą; глаголы на -ę: ty − esz/isz), сверенный с примерами courseofpolish/Dziwirek (у них основа — 3 л. ед. ч.; результат тот же). Можно заменить на один способ «от 3 л. ед. ч.».
- **tryb rozkazujący, R15 (утвердительный ndk звучит нетерпеливо / как приглашение):** оттенок вежливости подтверждён ZPE и courseofpolish лишь частично; в упражнении «Siadaj / Usiądź» принимаются оба ответа.
- **tryb rozkazujący, daj (от dać):** не включено — не нашлось двух источников с этой формой; можно добавить в список неправильных.
- **tryb rozkazujący, «-ij обычно»:** исключения (martw się, patrz) даны заметкой, без отдельного правила.
- **tryb przypuszczający, jeśli + by:** источники расходятся (Polski Daily допускает «jeśli bym miał», elon.io считает ошибкой) — учим и принимаем только gdyby.
- **tryb przypuszczający, по одному источнику (даны одной строкой/заметкой):** раздельное «trzeba by, można by» (ZPE), gdyby о прошлом с «wtedy» (elon.io), необязательное «to» в главной части (Polski Daily), «Na twoim miejscu…» (elon.io).
- **tryb przypuszczający, ударение и форма byłbym zrobił:** не включены (источники расходятся по ударению; прошедшее условное на B1 не нужно).
- **czasowniki ruchu, объём:** подробно — iść/chodzić, jechać/jeździć и приставочные от них; lecieć/latać, biec/biegać, płynąć/pływać, nieść/nosić, wieźć/wozić — только в таблице пар и нескольких пунктах. Приставки roz-/u- не включены (не нашлось двух источников).
- **czasowniki ruchu, слова с «na»:** правило «na + Biernik для ограниченного круга слов» подтверждено; конкретные слова (na pocztę, na dworzec) — стандартная лексика, не из списков источников.
- **dopełniacz po negacji:** окончания родительного падежа не объясняются заново — тема ссылается на тему «Dopełniacz» (prereq). «być + творительный не меняется» и «Nie kawę piję, ale herbatę» — по одному источнику; «ich → ich» — по стандартной парадигме.
- **dopełniacz po negacji, «Lubię oglądać seriali/serialów»:** принимаются обе формы родительного мн. ч.
- **Порядок после темы 8 (выбран по логике B1-экзамена):** 9 числительные с существительными (dwa/dwie/dwaj, pięć + Dopełniacz, согласование глагола) → 10 придаточные с który → 11 żeby / aby (цель) → 12 страдательный залог.
- **liczebniki:** объём B1 — только именительный/винительный (сколько чего есть). Склонение самих числительных (z pięcioma kolegami, ośmiuset) не разбирается — отдельная тема на будущее.
- **liczebniki, dwaj vs dwóch:** обе формы даны как правильные; согласование глагола тренируется только на «dwóch … przyszło». Форма глагола с dwaj (dwaj panowie przyszli) явно в источниках не сформулирована, поэтому в упражнениях не проверяется.
- **liczebniki, «pięć pokoi / pokojów»:** принимаются обе формы.
- **zdania z który:** таблица склонения в источниках дана картинкой — формы сверены с примерами в тексте и адъективным склонением. «co» после to/wszystko — по одному источнику. Относительное «gdzie» (miasto, gdzie…) не включено.
- **Проверка регистра:** где ответ стоит в начале предложения, добавлены варианты с заглавной буквы; лучше, чтобы движок сравнивал ответы без учёта регистра.
- **Подсказка «как в русском: делать / сделать»** — методический совет, а не правило, поэтому без источников.
- **Порядок тем после aspektu:** 5 tryb rozkazujący (опирается на вид: dk в просьбах, ndk в запретах) → 6 tryb przypuszczający → 7 глаголы движения → 8 dopełniacz po negacji.
